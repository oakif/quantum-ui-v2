## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `type` | `string` | `"text"` |
| `placeholder` | `string` | - |
| `disabled` | `boolean` | `false` |
| `className` | `string` | - |

Accepts all standard HTML `<input>` props.
