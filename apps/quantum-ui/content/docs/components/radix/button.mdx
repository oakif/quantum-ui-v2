## Usage

```tsx
import { Button } from "@/components/ui/button"
```

```tsx
<Button>Click me</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="outline">Outline</Button>
```

## Variants

| Variant | Description |
| --- | --- |
| `default` | Primary action, solid background |
| `secondary` | Secondary action, muted background |
| `outline` | Bordered with transparent background |
| `ghost` | No background, hover reveals fill |
| `destructive` | Danger/delete actions |
| `link` | Styled as a text link |

## Sizes

| Size | Description |
| --- | --- |
| `default` | Standard height (h-9) |
| `xs` | Extra small (h-6) |
| `sm` | Small (h-8) |
| `lg` | Large (h-10) |
| `icon` | Square icon button (size-9) |
| `icon-xs` | Small icon button (size-6) |
| `icon-sm` | Medium icon button (size-8) |
| `icon-lg` | Large icon button (size-10) |

## With Icons

Icons are automatically sized to `size-4`. Use `has-[>svg]` padding adjustments for proper spacing.

```tsx
import { Mail } from "lucide-react"

<Button>
  <Mail />
  Login with Email
</Button>
```

## Loading State

Use a spinner icon with `animate-spin` and optionally disable the button.

```tsx
import { Loader2 } from "lucide-react"

<Button disabled>
  <Loader2 className="animate-spin" />
  Please wait
</Button>
```

## As Child

Use `asChild` to render another element (like a link) with button styling.

```tsx
import Link from "next/link"

<Button asChild>
  <Link href="/dashboard">Go to Dashboard</Link>
</Button>
```
