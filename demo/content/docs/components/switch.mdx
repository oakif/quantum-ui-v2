## API Reference

| Prop | Type | Default |

| `checked` | `boolean` | - |

| `label` | `string` | - |
| `description` | `string` | - |
| `color` | `string` | - |

| `reverse` | `boolean` | `false` |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` |

| `className` | `string` | - |
