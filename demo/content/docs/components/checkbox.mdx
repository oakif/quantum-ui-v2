## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox"
```

```tsx
<Checkbox label="Accept terms and conditions" />
```

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | - |
| `invalid` | `boolean` | `false` |
| `checked` | `boolean` | - |
| `defaultChecked` | `boolean` | - |
| `onCheckedChange` | `(checked: boolean) => void` | - |
| `disabled` | `boolean` | `false` |
