## Usage

```tsx
import { Button } from "@/components/ui/button"
```

```tsx
<Button variant="outline">Button</Button>
```

## Examples

### Variants

Use the `variant` prop to change the visual style of the button.

<ButtonVariantsPreview />

| Variant | Description |
| --- | --- |
| `default` | Primary action, solid background |
| `secondary` | Secondary action, muted background |
| `outline` | Bordered with transparent background |
| `ghost` | No background, hover reveals fill |
| `destructive` | Danger/delete actions |
| `link` | Styled as a text link |

### Sizes

Use the `size` prop to change the size of the button.

<ButtonSizesPreview />

| Size | Description |
| --- | --- |
| `default` | Standard height (h-9) |
| `xs` | Extra small (h-6) |
| `sm` | Small (h-8) |
| `lg` | Large (h-10) |

### Icon Buttons

Use icon sizes for circular buttons containing only an icon.

<ButtonIconsPreview />

| Size | Description |
| --- | --- |
| `icon` | Standard icon button (size-9) |
| `icon-xs` | Extra small (size-6) |
| `icon-sm` | Small (size-8) |
| `icon-lg` | Large (size-10) |

### With Icon

Icons are automatically sized to `size-4`.

<ButtonWithIconsPreview />

### Loading

Use a spinner icon with `animate-spin` and disable the button.

<ButtonLoadingPreview />

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"` | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
| `asChild` | `boolean` | `false` |
