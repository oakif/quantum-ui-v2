## Usage

```tsx
import { DataTable } from "@/components/ui/data-table/data-table"
import { DataTableColumnHeader } from "@/components/ui/data-table/data-table-column-header"
import { DataTableToolbar } from "@/components/ui/data-table/data-table-toolbar"
```

```tsx
const table = useReactTable({ data, columns, ... })

<DataTable table={table} />
```

## Examples

### Resizable Columns

Use the `resizable` prop to enable column resizing. Drag between column headers to adjust widths — a ghost indicator line appears during drag and snaps on release.

<DataTableResizablePreview />

### Sticky Header

Use `stickyHeader` with a fixed `height` to pin the header while scrolling the body. The header gets a translucent backdrop blur effect.

<DataTableStickyHeaderPreview />

### With Toolbar & Filters

Pass `DataTableToolbar` as children to add search, faceted filters, and view options. Columns with `meta.variant` and `meta.options` are auto-discovered as filterable.

<DataTableToolbarPreview />

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `table` | `Table<TData>` | Required |
| `resizable` | `boolean` | `false` |
| `stickyHeader` | `boolean` | `false` |
| `height` | `string` | - |
| `recordCount` | `number` | auto |
| `footerContent` | `ReactNode` | - |
| `actionBar` | `ReactNode` | - |
| `children` | `ReactNode` | - |

### Sub-components

| Component | Purpose |
| --- | --- |
| `DataTableColumnHeader` | Sortable column header with dropdown |
| `DataTablePagination` | Page size selector + navigation |
| `DataTableToolbar` | Search, filters, view options |
| `DataTableFacetedFilter` | Multi-select filter with popover |
| `DataTableViewOptions` | Column visibility toggles |
| `DataTableSkeleton` | Loading placeholder |
