## Usage

```tsx
import { DataTable } from "@/components/ui/data-table/data-table"
import { DataTableColumnHeader } from "@/components/ui/data-table/data-table-column-header"
```

```tsx
const table = useReactTable({ data, columns, ... })

<DataTable table={table} />
```

## Features

- Sorting (click column headers)
- Pagination with configurable page sizes
- Row selection with checkboxes
- Column visibility toggling
- Faceted filters (Notion-style)
- Smooth hover transitions

## API Reference

| Prop | Type | Default |
| --- | --- | --- |
| `table` | `Table<TData>` | Required |
| `actionBar` | `ReactNode` | - |
| `children` | `ReactNode` | - |

### Sub-components

| Component | Purpose |
| --- | --- |
| `DataTableColumnHeader` | Sortable column header with dropdown |
| `DataTablePagination` | Page size selector + navigation |
| `DataTableToolbar` | Search, filters, view options |
| `DataTableFacetedFilter` | Multi-select filter with popover |
| `DataTableViewOptions` | Column visibility toggles |
| `DataTableSkeleton` | Loading placeholder |
